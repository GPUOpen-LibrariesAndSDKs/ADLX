Demonstrates how to access video super resolution options, and perform related testing when programming with ADLX.

Command Prompts

Command PromptDescription
1 Display video super resolution support
2 Display current video super resolution state
3 Enable video super resolution
4 Disable video super resolution
M/m Display the main menu
Q/q Quit the application
