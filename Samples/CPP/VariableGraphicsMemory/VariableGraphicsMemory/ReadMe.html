Demonstrates how to obtain Variable Graphics Memory when programming with ADLX and perform related operations.

Command Prompts

Command PromptDescription
1 Get Variable Graphics Memory support.
2 Get Variable Graphics Memory default option.
3 Get Variable Graphics Memory current option.
4 Get Variable Graphics Memory available options.
5 Set Variable Graphics Memory available option.
M/m Display the command prompt menu.
Q/q Terminate the application.
