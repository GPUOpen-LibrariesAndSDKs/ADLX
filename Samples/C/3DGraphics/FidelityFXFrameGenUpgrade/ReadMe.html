Demonstrates how to access AMD FidelityFX Frame Generation Upgrade options, and perform related testing when programming with ADLX.

Command Prompts

Command PromptDescription
1 Display FidelityFX Frame Generation Upgrade support
2 Display current FidelityFX Frame Generation Upgrade state
3 Enable FidelityFX Frame Generation Upgrade
4 Disable FidelityFX Frame Generation Upgrade
5 Display FidelityFX Frame Generation Upgrade available ratios
6 Display FidelityFX Frame Generation Upgrade current ratio
7 Set FidelityFX Frame Generation Upgrade ratio
M/m Display the main menu
Q/q Quit the application
